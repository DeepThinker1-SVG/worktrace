# Worktrace

[English](README.md)

Worktrace 是一款本地优先的桌面工作计划工具，用清晰的结构组织日常工作。

新建一个工作计划，把工作拆成有层级的事件；进度、备注、标签、截止日期与变更记录都保存在一起。你的数据始终是位于本地文件夹中的普通 Markdown。

## 让计划跟得上实际工作

Worktrace 适合会在执行中不断调整的工作：

- 新建工作计划，建立多层级事件树。
- 为事件设置状态、标签、备注、创建时间、完成时间和截止日期。
- 在计划变化时移动、缩进、提升层级、归档或删除事件。
- 通过工作板、时间线、日历和统计，从不同角度查看同一份计划。

## 为不同问题准备的视图

### 工作板

用层级结构整理当前与已结束的事件；可以搜索、按状态或标签筛选，也可以直接在计划中编辑。

### 时间线

回顾重要变更：事件创建，以及标题、备注、状态、标签和截止日期的更新。

### 日历

查看工作何时创建、完成或到期；截止日期会与其他日期清晰区分。

### 统计

快速了解当前工作、已完成工作、阻塞事项、标签使用情况和近期活动趋势。

## 本地文件，而不是封闭的数据孤岛

选择一个本地工作区后，即可新建或打开工作计划。Worktrace 将计划保存为 Markdown，并把事件元数据维护在旁边，因此源文件始终可携带、可掌控。

你还可以浏览和打开工作区中的 Markdown 文件，设置需要监听的目录，并使用独立窗口持续查看重要文件。

## 开始使用

1. 打开 Worktrace。
2. 选择本地工作区，或打开已有的 Markdown 工作计划。
3. 新建一个工作计划并添加第一个事件。
4. 在工作板中持续更新工作；需要不同视角时切换到时间线、日历或统计。

## 下载

目前提供 Windows x64 安装包。请在 [GitHub Releases](../../releases/latest) 下载最新版。

## 开发

需要 Node.js 20 或更高版本。

```bash
npm ci
npm start
```

运行完整验证：

```bash
npm run verify
```
